# 干净镜像的隐私边界

镜像由安装包的文件清单重建，加入项目维护的通用模板。
不是把运行系统整份 tar 后只删除浏览器历史。

## 不从母版复制

- `/home`、`/root`、根目录下的配置/缓存/密钥目录。
- 浏览器配置、Cookies、登录、聊天与 Agent 状态、源代码及文件管理器历史。
- Clash/其他代理的数据目录、订阅、控制密钥和应用数据库。
- SSH 密钥、主机密钥、机器 ID、原密码散列、原 pacman 私有签名身份。
- `/proc`、`/sys`、`/dev`、`/run`、`/tmp` 的内容及宿主/SD 卡的挂载数据。
- 日志、审计输出、回滚备份、软件缓存和本地构建目录。
- 母版账号名、设备序列号、SD UUID和 Windows 用户路径。

`linux` / UID1000 是新建的通用技术账号。系统服务账号保留必要名称和编号，
不复制其密码或描述字段。镜像所有密码条目均锁定；首次安装交互设置新密码。
用户输入法词库从系统默认重新开始，不带入母版学习记录。

`/etc` 只复制软件包拥有的文件；对包管理器标记的配置文件检查 MD5，
不自动接受修改后的配置。特定 PAM、profile、shell、FUSE 改动经过白名单审核。
网络、sudo、软件源、身份等配置由模板或程序重新生成。
`/usr/local` 使用项目脚本白名单，不复制维护报告、测试文件或旧备份。

## 检查方式

构建时可输入一个 **不在项目内保存** 的私有标识模式文件，扫描副本内容。
模式文件不会写入镜像、报告或 Release。扫描结果只保存是否通过和数量。
发布检查还验证归档文件路径、链接、个人状态目录、密钥、密码条目和软件清单。

字符串扫描不是隐私保证的唯一依据：用户状态目录一开始就没有进入副本。
二进制和 APK 的内容也需检查；公开客户端重新编译时不保留本地调试信息。
重新打包不能把账号、代理等配置作为“功能默认值”保留下来。

Git 仓库只加入源码、文档、模板及脱敏报告。`dist/`、`.build/`、私钥等默认忽略。
发行签名私钥必须保留在仓库之外，不能因为私钥路径被忽略就把它存入公开归档。

检查依据及结果见 `reports/`。若手工修改或加入文件，必须重新校验，不能继续使用旧报告。
