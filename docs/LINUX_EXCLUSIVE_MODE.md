# Linux 独占冷启动模式 (Linux Exclusive Mode)

> **分支说明**：本项目 `main` 分支默认提供“双桌面随时无缝热切换（Android 与 Linux 并存）”方案。  
> 本分支（`linux-exclusive-mode`）专为 **“99% 场景仅使用 Linux、追求将全机 CPU/内存极致榨取归 Linux 所有、彻底舍弃随时热切换”** 的用户设计。

---

## 一、 为什么要做独占模式？

在默认的“双桌面随时切换”模式下，为了让用户随时通过手势或按钮瞬时切回 Android，原厂 Android 的桌面 Launcher、多任务服务、输入法及大量后台广播均处于常驻待命状态。这会产生两个弊端：
1. **内存分流**：Android 后台应用及 Launcher 持续占据 700MB ~ 1.3GB 的物理内存；
2. **算力争抢**：Android 后台服务和定时器随时可能跃迁到骁龙 870 的大核与超大核（3.2GHz）上执行，偶发产生微小卡顿；
3. **手势误触**：全屏写代码或浏览时，底部上滑易误触触发 Android 原生手势退出 Linux。

**Linux 独占模式的原则**：
* **单系统独占**：某一时刻设备只属于一个系统；
* **物理锁死**：注销 Android 桌面与 FallbackHome，手势彻底失效，屏幕 100% 锁定在 Linux；
* **深度冰封**：利用内核级 `cgroup v2 freezer` 将 Android 剩余非必要组件挂起（0% CPU 消耗）；
* **冷重启切换**：若需使用 Android，通过一键命令或开机硬件按键重启进入。

## 二、 实机压测与资源审计

在联想小新 Pad Pro 2021（TB-J716F / 骁龙 870 / 6GB RAM）实机上，独占模式实测数据如下：

### 1. 资源倾斜成果

| 维度 | 默认双桌面并存模式 | Linux 独占模式 (本分支) | 优化收益 |
| :--- | :--- | :--- | :--- |
| **Android 应用层活跃进程** | 37 个 | 仅剩 1 个输入法 + 底层驱动代理 | **减少 15+ 个驻留进程** |
| **Android 应用层占用 (RSS)** | ~1,320 MB | ~561 MB | **净收回 760 MB+ 物理内存 (降幅 57.5%)** |
| **Android 原生桌面 (Launcher)** | 182 MB (全天候常驻) | **0 MB (彻底注销抹除)** | **100% 消除** |
| **大核 (CPU 4-7, 3.2GHz) 独占** | 混杂争抢 | **100% 专供 Linux** (Android 后台锁死在小核 0-3) | **重载编译/3D渲染无后台抢频** |
| **冻结进程 CPU 消耗** | 频繁定时器唤醒 | **严格为 0 微秒** (5秒窗口实测增量为0) | **彻底消除周期性微卡顿** |

## 三、 使用与切换方法

### 1. 日常（99% 场景）：纯粹使用 Linux
* **开机**：按电源键正常开机即可。系统自动启动 Linux，并在加载完成后自动执行深度冰封，锁定屏幕与算力。
* **交互防误触**：屏幕底部上滑、双击、按多任务键均无法离开 Linux 桌面。

### 2. 需要使用 Android（1% 场景）：冷重启切换
有以下两种最便捷的途径：

* **途径 A（在 Linux 桌面中操作）**：
  * 在终端运行：`switch-os`（或 `reboot-android`）；
  * 或在 KDE 开始菜单中直接点击 **“切换系统 (Switch to Android)”**；
  * 菜单中选择 `1) 重启进入 Android (单次)`，系统将自动恢复 Launcher 并重启进入完整的原厂 Android 平板系统。
* **途径 B（开机物理盲切）**：
  * 平板关机或重启时，在开机最初的 3 秒内**按住平板的「音量减键」**，系统检测到按键后将直接留在 Android，不启动 Linux。

### 3. 从 Android 切回 Linux
* 若此前选择的是“单次进入 Android”，直接在电源菜单点击**重启**，开机自动回到 Linux 独占模式；
* 亦可在 Android 存储中运行 `/sdcard/switch_to_linux.sh`，或在 Termux 中执行 `switch-to-linux` 一键重启回 Linux。

## 四、 本分支新增与变更的脚本清单

* `scripts/android/freeze_android.sh`: 深度冰封脚本（禁用 Launcher、冻结后台 UID、分配 CPU 亲和性、清理 Cache）；
* `scripts/android/unfreeze_android.sh`: 恢复与解冻脚本（启用 Launcher、恢复 cgroup 冻结队列）；
* `scripts/android/launch_kde_desktop.sh`: 桌面启动后自动调度 Stage C 深度冰封；
* `scripts/android/start_kde_boot.sh`: 开机调度器（支持 `linux` 模式识别与音量键判断）；
* `scripts/android/linux-host-bridge.sh`: 宿主桥命令处理器（新增重启、冰封与状态查询命令）；
* `scripts/linux/switch-os`: Linux 内部的交互式多功能系统切换 CLI 工具；
* `templates/switch-os.desktop`: KDE 桌面应用菜单快捷方式；
* `scripts/android/switch_to_linux.sh`: Android 端的切回工具。
